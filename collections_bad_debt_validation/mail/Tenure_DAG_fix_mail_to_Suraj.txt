I validated analytics.collections_bad_debt_mv against the Collections Raw_Data Sheet. tenure_days does not follow the business rule, so it does not match. Could you please pick this up and update the DAG?

SUMMARY OF THE PROBLEM
- Rule: tenure should be counted only up to the driven week end (hissab_week - 1).
- The DAG today counts up to the Sunday of the hisaab week (hissab_week + 6). For active partners, tenure comes out about 7 days too high.
- Only 11.3% of rows match the rule today, across 9 weeks (10 Aug - 5 Oct, 102,909 partners).
- If the 7-day gap is ignored, 92.2% match. The remaining misses are in older weeks, where driver_profile changed after those weeks were built. Those weeks need a backfill.

WHAT NEEDS TO CHANGE IN THE DAG
Replace the current tenure_days logic with the CTE below and join it on (hissab_week, partner_etm). <mv base rows> stands for the per-week, per-partner base CTE the DAG already builds.

tenure_fix as (
  select m.hissab_week, m.partner_etm,
         coalesce(sum(least(coalesce(dp.end_date::date, m.hissab_week - 1), m.hissab_week - 1)
                      - dp.start_date::date + 1)
                  filter (where dp.start_date::date <= m.hissab_week - 1), 0) as tenure_days
  from <mv base rows> m
  left join fleet_driver   fd on fd.employee_id = m.partner_etm
  left join driver_profile dp on dp.driver_id  = fd.id
  group by m.hissab_week, m.partner_etm
)
-- final select: tenure_fix.tenure_days as tenure_days

Tenure is the sum of all driver_profile stints (end - start + 1). The running stint is cut at the driven week end, and stints that start later are not counted. fleet_driver.employee_id is unique, so the join does not double count.

with t as (
  select m.hissab_week, m.id, m.tenure_days,
         coalesce(sum(least(coalesce(dp.end_date::date, m.hissab_week - 1), m.hissab_week - 1) - dp.start_date::date + 1)
                  filter (where dp.start_date::date <= m.hissab_week - 1), 0) as logic
  from analytics.collections_bad_debt_mv m
  left join fleet_driver   fd on fd.employee_id = m.partner_etm
  left join driver_profile dp on dp.driver_id  = fd.id
  where m.hissab_week >= '2026-08-10'
  group by m.hissab_week, m.id, m.tenure_days
)
select hissab_week, count(*) as rows,
       count(*) filter (where tenure_days is distinct from logic) as different
from t group by 1 order by 1;
